# 道闸玩具（toys_daozha）

道闸（barrier gate）造型的儿童玩具。**语音是核心**：ESP32-S3 + ESP-SR 离线识别，只认三条命令——起杆 / 落杆 / 复位。配一个 ESP-NOW 直连的三键遥控器。目标玩家 6~10 岁。

## 关键约束（改任何东西前先看这几条）

1. **转轴离地 42mm、杆顶 46mm** —— 用户小车最矮 50mm，必须低于它。CAD 里 `PIV_Z = PIVOT_ABS − BASE_H` 自动保持，**别直接改 `PIV_Z`**
2. **排母只买低背 5.0mm** —— 常见的 8.5mm 装不下
3. **限位开关必须带簧片杠杆** —— 无杠杆直动式行程 0.3mm，会被 3.3mm 的凸轮升程压毁
4. **防砸是行程超时，不是电流检测** —— 延迟 0.2~1.6s、压紧力约 1.3N。成品 DRV8833 模块不引出 AISEN，电流检测做不了
5. **先定元件再改 CAD** —— 本项目 v2.2~v2.6 连续修的硬伤，根因都是拿没核实的尺寸建模

## 工具环境

- **OpenSCAD** 装在 `F:\Program Files\OpenSCAD\openscad.exe`（不在 PATH）
- **OpenSCAD 在中文路径下无法渲染** → CAD 工作副本放 `D:\cad\`，改完再同步回 `cad\`
- 命令行用数字选择器 `-D p=N`，别用 `-D part="x"`（PowerShell 会吞引号）
- 嘉立创EDA 桥接已跑通，见 `easyeda-api` skill
