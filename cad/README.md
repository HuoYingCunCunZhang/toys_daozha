## v3.0 改了什么

### 🔴 计划外的一条：闸体原来正压在起杆按键上

PCB 定稿把两个按键放到 **(0, +20) 和 (+20, +20)**，而闸体占 **x = 2…48** —— x=20 那颗按键整个被闸体盖住，手指根本够不到。

v2.6 的参数区里其实写着「按键 x < 2，因为闸体占 2…48」，但**按键位置后来改由 PCB 定**，没人回头看那条注释。这类"约束写在被约束的一方，改动发生在另一方"的失配，布尔自检抓不到——两者根本不在同一个零件里，求交永远是空的。

按项目原则（**结构让路给 PCB**）只能挪闸体：`HS_X_ABS` **25 → 55**，闸体改占 x = 32…78，离按键边缘 7.75mm。顺带也更像真道闸——底座放大到 183 之后，闸体待在 x=25 会把 +X 侧空出 43mm。

> **代价**：上盖走线孔跟着挪到电池上方（55, −16.5）。闸体下来的飞线要贴着电池顶面（有 10mm 空隙）往 −X 走到板子上。电池自己的引线也是朝 −X，同一条通道。

### 按键帽的法兰厚度是被"按不按得动"卡住的

帽子能下压的距离 = **沉孔总深 4.0 − 法兰厚**，而按下去要走 **0.2**（预留浮动，免得静止时就预压住开关）+ **0.25**（开关行程）= **0.45mm**。

法兰取 3.5 就只剩 0.5mm 可压，余量 **0.05mm** —— 打印公差 ±0.15 就能让法兰先坐死在沉孔底上，**开关根本压不到**。所以取 **3.0**，余量 0.55mm；导向也不受影响（法兰 3.0 + 柄在通孔里 1.5，跨距仍有 4.5mm）。

> 这类"**两个尺寸之差**决定功能"的地方，单看任何一个数字都很正常，布尔自检也测不出来（帽子确实坐得进、确实拔不出）。只能靠把行程链算一遍。

### 转毂为什么必须拆

| | |
|---|---|
| 左壳 −Y 壁上的轴颈孔 | **φ8.5** |
| 夹杆臂（壁外） | 36 × 14 |
| 凸轮（壁内） | φ18.6 |

两端都远大于 φ8.5，而分模面在 y=0、这道壁整个属于左壳，**拆开左右壳也分不开它**。

**拆凸轮而不是拆臂**：凸轮几乎不受力（只拨开关），闸杆弯矩和电机扭矩全部走主体这一整件。

新方案的固定链：

- **角度**靠 `cam` 的 D 形孔配轴颈上的**键面**定死 —— 不靠装配时把顶丝拧到某个角度去猜时序
- **轴向**靠几何夹：往 −Y 拔 → 凸轮撞轴承凸台；往 +Y 推 → 夹杆臂撞外壁（只有 1mm 行程）
- **顶丝**只负责把凸轮锁在轴颈上。它长在凸起的**背面**，全程扫 −X/−Z 那个空象限，永远碰不到开关
- 顶丝是径向的，从分模面伸手够不着 → **闸体前面板上开了一个 φ3 进入孔**，闸杆放到落杆位时顶丝正对它，长柄小螺丝刀直接捅进去拧

## 自检怎么跑

```powershell
.\run_check.ps1
```

`check.scad` 是布尔交集自检，`run_check.ps1` 把 **59 条用例**跑一遍并与期望值比对（主机 43 + 遥控器 16；跑满一轮约 30 分钟，`t=16` / `t=44` 那种多角度扫掠最慢）。

**期望表就在 `run_check.ps1` 里，改用例记得同步。里面 24 条是阳性对照（必须非空）——别删。** 没有阳性对照的自检失效了也不会报警，v2.2 就是这么栽的。

> **阳性对照要覆盖"东西根本不存在"这种情况。** `t=17/18` 验了开关底孔"没打穿外壁"和"是通的"，可是**整块安装台不存在时这两条照样过**——没有料，求交当然是空的。所以另加了 `t=55/56` 验孔四周有料，而且**两块安装台必须分开验**：合在一个用例里，只要有一块在就非空了。

单跑一条：`.\run_check.ps1 -Only 40`

### 新增的关键用例：装配路径

```
t=40  转毂上要穿过 φ8.5 壁孔的那一段, 减掉壁孔通道后必须什么都不剩   -> EMPTY
t=41  阳性对照: 把凸轮装回去(= v2.6 的一整件)后同样的判定必须非空   -> NON-EMPTY
```

这条专治「静态求交测不出装配路径」那个盲区：`t=16` 早就验过转毂在最终位置不干涉闸体，但**一整件根本走不到那个位置**。

### 新增的关键用例：跨零件失配

```
t=53  按键帽 vs 闸体                              -> EMPTY
t=54  阳性对照: 闸体放回 x=25 必须压住按键帽       -> NON-EMPTY
```

就是上面那条硬伤的回归测试。**这类问题只有把两个零件摆到装配位置去求交才看得见**——单看任何一个零件都完全正常。

### ⚠ 写用例的铁律：不许留共面接触

两个实体面贴面求交，CGAL 给的是**零体积薄片**，导出 STL 有几百个三角形，看文件大小会被判成"非空"。v3.0 第一轮就这么冒出 5 条假失败：

| 假失败 | 真相 |
|---|---|
| 托盘 vs 上盖 | 交集 bbox `z[22.00..22.00]` —— 就是贴合面本身 |
| 遥控下壳 vs 上壳 | `z[17.00..17.00]` |
| 电芯 vs 托盘 | `x[36.00..36.00]` —— 电芯 −X 面贴着挡边 |
| 转毂穿壁孔判定 | `z[11.00..11.00]` —— 判定用的半空间正好切在夹持段顶面 |
| 闸杆底孔探针 | 这条是**真的**：拿 φ2.0 探针去探 φ1.7 自攻底孔，当然探不通 |

处置：凡"应该刚好贴上"的地方一律错开 0.01~0.05 再求交；探自攻底孔用 `PROBE_S`(1.4)，探 M2 过孔才用 `PROBE`(2.0)。
原 `t=1` / `t=2`（上下壳直接求交）已删除，作用被 `t=13` / `t=14`（抬 0.01）完全覆盖。

> 判定"空/非空"是看导出 STL 的大小。所以一个零体积薄片会被误判 —— 这就是上面那条铁律的由来。

### 遥控器那 16 条又踩了同样的坑两次

- **`t=60` 板 vs 下壳**：第一版拿一块**没有螺柱缺口**的方板去求交，撞的是我自己画错的测试模型，不是设计缺陷。**测试模型必须和真件同形**。
- **同一条又漏了 Z 向贴合面**：只在 XY 缩了 0.05，交集出来是 `z[7.10..7.10]` 的零厚度薄片 —— 那是板本来就该坐在螺柱承托肩上的贴合面。**缩要三个方向一起缩。**
- **`t=71` 阳性对照本身是失效的**：原来拿 12mm 高的开关当"必须撞上盖"的对照，可板面 8.7 + 12 = 20.7 根本够不到 23 的盖背面 —— **这个对照永远会过，等于没设**。改成 16mm 才成立。
  > 阳性对照也要验算，不能想当然。一个永远通过的对照比没有对照更危险，因为它给人"我有对照"的错觉。

### 自检还没覆盖的（知道就好，别以为全过就万事大吉）

| 没测的 | 现在靠什么保证 |
|---|---|
| **止口环下方那圈的净高**（14.4mm）| `t=22` 只测中央区。环下方靠[机械约束 §三](../道闸玩具_底板机械约束_v1.md)那张叠高表手算——最高的是 U2 的 12.5，余 1.9mm。要自动化的话得拿 `layout()` 里的元件块去和上盖求交 |
| **元件实际外形** | `layout()` 里都是长方块近似，不是真封装 |
| **打印公差** | 全部按名义尺寸建模。`GAP` / `CAP_CLR` 要按自己的机器调 |
| **受力** | 纯几何，没有任何强度校核 |

## 看爆炸图

```powershell
& "F:\Program Files\OpenSCAD\openscad.exe" -D p=13 -o png\explode.png --imgsize=1500,1300 --camera=60,-45,105,64,0,22,720 daozha.scad
```

GUI 里把文件头的 `part` 改成 `"explode"` 也一样。出图见 [`png/explode.png`](png/explode.png)。

原理是**同一个 `assembly()` 出两种图**，靠 `EXP` 系数撑开：

| EXP | 结果 |
|---|---|
| 0 | 装配态（`p=0`）|
| 1 | 完全炸开（`p=13`）|
| 0~1 之间 | 半程，见 [`png/explode_half.png`](png/explode_half.png) |

所以做**装配动画**只要扫这个值：

```powershell
0..20 | ForEach-Object { $v = $_ / 20.0
  & "F:\Program Files\OpenSCAD\openscad.exe" -D p=0 -D "EXP=$v" -o "png\anim_$('{0:d2}' -f $_).png" --imgsize=900,780 --camera=60,-45,105,64,0,22,720 daozha.scad }
```

（`-D` 赋的值会覆盖文件里的定义，所以 `-D EXP=0.45` 能压过 `p` 推出来的那个 0/1。）

**炸开方向不是随便挑的，一律取零件真实的装配方向**，这样爆炸图同时就是装配顺序图：

| 零件 | 方向 | 为什么 |
|---|---|---|
| 承载底板 / 上盖 / 按键帽 | +Z | 自下而上叠 |
| 闸体左右壳 | ∓Y | 沿分模面掰开 |
| 凸轮 → 转毂 | −Y（凸轮近、转毂远）| 沿转轴轴向抽出。**顺序就是拆的顺序**：先退凸轮才能拔转毂 |
| 闸杆两段 | +X | 顺着插槽方向拔 |
| 电池 | −Y | 从仓里侧向取出 |

每个零件还画一条**引导线**，从它的装配位置连到炸开位置（`GUIDE = false` 可关掉）。
`ex(位移, 锚点)` 的第二个参数就是画线用的锚点，新加零件时补上即可。

> 电池、承载底板和板上元件（DevKit / TP4056 / 升压 / 端子 / 按键…）现在也进了 `assembly()`，
> 所以爆炸图能直接当装配示意图看。它们都是**长方块近似**，不是真封装。

## 遥控器（v3.1，按 PCB 定稿反推）

**外壳 63 × 40 × 26**，全部尺寸都是被算出来的，不是挑的：

| 方向 | 被什么锁死 |
|---|---|
| 长 63 | **双向锁死**：−X 端拨柄尖在 x=−32.5，外壁面必须落在 −31.5 才露得出来；+X 端 USB 插头壳长只有 6.5mm。内腔加长任何一边都会失效 |
| 宽 40 | 板 33 宽 + 两侧让位。板本身为了给螺柱腾缺口，已经往 −Y 加宽 3mm 做了条纯安装边 |
| 高 26 | 地板 2 + 电池 **4.6** + 支撑 0.5 + 板 1.6 + U1 叠高 **11.7** + 上盖 3 |

**坐标系有两套**：PCB 用它自己的原点（板 x ±28.5、y −18…+15），外壳是对称 rbox，差一个 `RC_PCB_DY = 1.5` 的 Y 偏移。凡是"对准板上某器件"的特征一律写 PCB 坐标再加偏移，**别直接填外壳坐标**。

### 两条是自检抓出来的，不是算出来的

1. **外壳高度只能是 26，不能是 24**。24 时上盖背面在 21，而按键帽的 φ11 导向凸台往下伸 2mm 到 19 —— 而 U1 叠高顶面在 20.4，**凸台正撞在模块上**。凸台位置由 PCB 的按键坐标定死（SW3 在 x=20，压在 U1 正上方），挪不了。（`t=64`）
2. **U1 必须插低背排母**（要反复拔下来改程序），叠高 6.7 → 11.7。

### ❌ 不开第二个 Type-C

充电器插错到 C3 那个口时，5V 会经 5V 脚 → 拨动开关 → TP4056 的 OUT+，而 OUT+ 与 B+ 直连（保护只切负极）= 直接怼电池。开发板烧不了，但那是靠 DW01 救命。**改成拆壳拔模块烧录。**

## 打印参数

- 层高 0.16mm（闸杆、转毂、凸轮、按键帽）/ 0.2mm（外壳）
- 壁 3 圈（闸杆壁只有 1.2mm，靠外圈保证强度）
- 填充 20%（外壳）/ 100%（转毂、凸轮）
- 闸杆**不要**加支撑，中空腔是设计好的；根段两端已开 φ2 排料孔
- 按键帽下柄做成了锥形（φ8 → φ12），就是为了不出现 2mm 的水平悬空，别改成直柱

## 装配顺序

**完整六阶段流程见 [采购与装配清单 §5](../道闸玩具_采购与装配清单_v1.md)**。CAD 这边只强调三条：

1. **按键帽必须在扣上盖之前从背面放进沉孔**（法兰 φ12 比通孔 φ9 大，从正面塞不进去）
2. **转毂从壁外插进去、凸轮从腔内套上**，然后从前面板的 φ3 孔拧顶丝。顺序反了装不上
3. **限位开关先松着拧**，通电试到"凸起刚好压下、基圆刚好释放"再拧紧长圆孔

## 内部排布

以 [底板机械约束 §七之二](../道闸玩具_底板机械约束_v1.md) 为准。`layout` 视图（`-D p=1`）里的元件**全部按 PCB 定稿坐标摆**，不是示意位置。

## 建模时踩过的坑（改参数时注意）

1. **内腔挖空高度必须是 `HS_H - 2*WALL`**，写成 `HS_H` 会把顶盖捅穿。
2. **带孔的螺柱不能在挖完内腔后 union 上去**——union 会把底孔在底板那 2mm 里重新填实，孔变成上下封死的盲腔。正确顺序是：先 (壳体 − 内腔)，再并实体特征，**最后统一开孔**。v3.0 的轴颈孔就是因此挪到最后开的：它要一次穿透 −Y 壁**和后加的轴承凸台**，留在原地会被凸台重新填实。
3. **不要让特征"刚好相切"**到底板/顶盖。相切接触产生非流形边（`Simple: no`）。所有接合都要真实互穿 ≥1mm。
4. **底座内部特征必须写在 `difference()` 之外**，否则会被内腔一起减掉。
5. **盖板背面的 2mm 止口是隐形杀手**（v2.3 的 1、2 两条都栽在它上面）。改任何与盖板相关的尺寸时问自己两句：孔打穿它了吗？下壳的螺柱给它让位了吗？现在这两处都统一走 `LIP_T` 参数，别再写死 2。
6. **沉头孔翻转 180° 时，`csk()` 的 `h` 必须是"到沉窝所在面"的完整厚度**，不是面板厚度。
7. **转毂的局部坐标不等于装配坐标**：装配时 `rotate([-90,0,0])`，映射是 局部 Y → 装配 −Z、局部 Z → 装配 +Y。凡是给转毂加特征，先把这条映射写在注释里再动手。
8. **左右对开壳的对拧螺柱必须两边都有**：一边出螺纹柱，另一边出同径导向柱撑到分模面。
9. **`rbox` 是实心的**。用它做"止口"会得到一整块板而不是一圈边，把内腔净高整个吃掉 2mm——而且这块板在渲染图里几乎看不出来。想做"环/框"记得再挖一次中央。
10. **内腔净高是分区的**：中央区（`|x|<LIP_IN_X` 且 `|y|<LIP_IN_Y`）到 z=`TRAY_H`，止口环下方只到 `TRAY_H−LIP_T`。当前是 22 / 20。给元件排位置前先确认它在哪个区。
11. **别把尺寸链写死**。`PIV_Z` 原来硬编码 22，其实是"转轴离地 42 − 底座高"的结果；一旦调底座高度就会悄悄违反锁定的转轴高度。现在写成 `PIVOT_ABS - BASE_H`，约束才真的被表达出来。v3.0 底座从 22 加到 25，`PIV_Z` 自动从 20 变 17，转轴离地仍是 42。
12. **转动件的限位不能靠"把挡块摆到那个角度"**。挡块必须待在转动件的**扫掠包络之外**，包络由"侧面到转轴的距离"决定而不是角度。用**扫掠差集**让几何自己算出挡块该在哪。
13. **做扫掠并集要对相邻位置取 `hull()`**。只把离散角度的实例并起来，在"角度覆盖变窄"的半径上会漏出细缝，差集之后变成提前挡路的毛刺。实测 5° 步长的漏缝让闸杆 85° 就撞上。
14. **D 形孔是 圆 ∩ 半空间，不是 圆 ∪ 方槽**。写成并集的话孔比轴还大，D 面完全没起作用，轴插进去空转——渲染图上还挺像那么回事。自检里用"整根圆柱必须插不进去"当阳性对照（`t=31`）。
15. **N20 机身是 10×12 方形，不是圆的**。按圆柱建模的话对角线 15.6mm 根本塞不进去。
16. **（v3.0 新）约束注释要写在会被改动的那一方**。"按键 x<2 因为闸体占 2..48"写在按键参数旁边，但真正会变的是按键位置的来源（PCB）和闸体位置，结果两边都改了、注释没人看。这类跨零件的失配布尔自检抓不到——两者不在同一个零件里，求交永远是空的。
17. **（v3.0 新）自检用例里不许留共面接触**，会出零体积薄片被误判成"非空"。详见上面自检那节。
18. **（v3.0 新）探针直径要配孔的类型**。φ2.0 探 M2 过孔（φ2.4）合适，探自攻底孔（φ1.7）永远探不通——那是探针选错了，不是零件有毛病。
