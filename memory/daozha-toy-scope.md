## 工具环境

- OpenSCAD 2021.01 在 `F:\Program Files\OpenSCAD\openscad.exe`（不在 PATH）
- **OpenSCAD 在中文路径下无法渲染** → 工作副本放 `D:\cad\`，改完同步回 `cad\`
- 命令行用数字选择器 `-D p=N`，别用 `-D part="x"`（PowerShell 吞引号）
- **写带中文的 .ps1 必须存成 UTF-8 with BOM**：Windows PowerShell 5.1 没有 BOM 就按 ANSI 读，中文全变乱码并报语法错。补救 `(Get-Content -Raw -Encoding UTF8 $p) | Out-File $p -Encoding utf8`。.scad 无所谓（OpenSCAD 认无 BOM 的 UTF-8）
- **PowerShell 的 `[ordered]@{}` 用整数下标取到的是"第几个"，不是键**。`$h[1]` 拿的是第 2 条。要按键取值就 `GetEnumerator()` 遍历——这个 off-by-one 让自检结果和期望值整体错了一位，差点当成真失败去改模型
- 嘉立创EDA 桥接已跑通，见 `easyeda-api` skill 与 [[easyeda-bridge-setup]]

## 锁定决策

- **语音是核心**：ESP32-S3-DevKitC-1 **N16R8** + ESP-SR，仅 3 条命令（起杆/落杆/复位）。**无喇叭/无TTS/无录音回放**
- **无爆闪灯、无闸杆灯带**；指示灯方案 = **在模块自带灯正上方开观察孔**（底座对 TP4056 充电灯，遥控器对 C3 板载蓝灯）
- **防砸 = 行程超时反转**（落杆超 1.15×T 反转、超 1.5×T 进 FAULT）。⚠️ 曾定"堵转电流检测"，**已推翻**——成品 DRV8833 模块不引出 `AISEN`，电机电流不经过 `GND` 脚，电阻串 GND 只能读到几 mA 静态电流。代价：响应从毫秒级变**秒级（0.2~1.6s）**、压紧力约 1.3N
- 玩家 6~10 岁
- **尺寸**：底座 **183×73×25**，承载底板 **120×65**（换算 `BASE_L=板长+63`、`BASE_W=板宽+8`）；闸体 46×46×62；闸杆 300×5×8 **从按键相反侧(+X)伸出**；**转轴离地 42、杆顶 46**（用户小车最矮 50，必须低于它）；起杆 90°；底座 2 键；Type-C + 总开关在**前端面**；遥控器 60×30×20 三键
- **转毂拆成 `hub`（主体，一整件）+ `cam`（凸轮盘）** —— 拆件与电机固定无关，是壁孔 φ8.5 卡住了 φ18.6 凸轮和 36×14 臂。拆点选凸轮而非臂：凸轮不传扭矩不受弯，主体保持整体承力
- **电机只靠矩形隧道夹紧**，不做 M1.6 支架板（端面 M1.6 孔留作日后加固）

## CAD v3.0（2026-08-14 解冻，12 项改完）

**12 个零件**：base_tray / base_top / house_l / house_r / hub / **cam(新)** / **btn_cap ×2(新)** / bar_a / bar_b / rc_bottom / rc_top。全部 `Volumes=2 / Simple=yes`，`cad/run_check.ps1` 43 条用例全过（含 16 条阳性对照，跑满一轮约 25 分钟）。

🔴 **计划外抓到一条硬伤：闸体原来正压在起杆按键上。** PCB 定稿把按键放在 (0,+20)(+20,+20)，闸体占 x=2…48，x=20 那颗整个被盖住。**`HS_X_ABS` 25 → 55**（占 32…78）。连带上盖走线孔挪到 (55,−16.5)，在电池正上方，飞线贴电池顶面往 −X 走。

**转毂拆件后的固定链**（三者缺一不可）：角度靠 `cam` 的 **D 形孔配轴颈键面**定死（不用装配时对相位）；轴向靠几何夹（往外拔→凸轮撞 φ12 轴承凸台，往里推→夹杆臂撞外壁）；**顶丝只锁凸轮**，长在凸起背面（永远扫 −X/−Z 空象限），**闸体前面板开 φ3 进入孔**从外面拧——顶丝是径向的，从 y=0 分模面伸手够不着。⚠ 这颗顶丝是转毂唯一轴向固定，必须点螺纹胶。

**按键帽**：开关顶杆 17.6 / 盖面 25，差 7.4。帽 = 锥形下柄 + φ12 法兰(卡在背面 φ12.5 沉孔里) + φ8.5 柄露出 5mm。上盖背面加 **φ14×2.5 导向凸台**把沉孔从 1.5 加深到 **4.0**，导向跨距 4.5mm。**必须扣上盖前从背面放进去**。
⚠ **法兰厚 3.0 是算出来的，不是随手取的**：可压距离 = 沉孔深 4.0 − 法兰厚，必须大于 0.2(预留浮动，免得静止时预压开关) + 0.25(开关行程) = 0.45。取 3.5 只剩 0.05mm 余量，**打印公差 ±0.15 就能让法兰先坐死在沉孔底、开关根本压不到**。这类"两个尺寸之差决定功能"的地方，光看单个数字看不出问题。

## 遥控器（2026-08-15 起做，流程与主机一致）

**用户拍板三条**：❌ 无状态灯（原方案的"板载 WS2812/蓝灯"取消，顺带了结了两份文档打架）、❌ 无电量检测（100k/100k 分压静态 18.5µA，而深睡指标 <20µA，电池只有 250mAh）、✅ **外壳尺寸可动，优先装得下**。

**与主机唯一的流程差异**：主机的底座能随便放大所以"结构让路给 PCB"；遥控器 60×30×20 是**手持尺寸**，所以"塞不塞得下"必须**提前算**，不能等画完 PCB。算下来原尺寸装不下：高度差 2mm（电池 7 + 板 1.6 + C3 叠高 6.7 要 16 净高）、平面占用率 **71%**（正是主机布不通的那个数）→ 目标 **68×32×22**，最终仍以 PCB 定稿反推。

**原理图已建并校验通过**（工程 `道闸玩具遥控器` uuid `ea4e1a7afdae48fc87c730f80a6c9114`）。8 条网络：VBAT / VBAT_N / VSYS / V5 / GND / BTN_UP / BTN_DN / BTN_RST。

- 🔴 **GPIO2 是 C3 的 strapping 脚**，上电必须为高，而按键是拉低的 —— 按着键开机可能起不来。三个键最终落 **GPIO4/3/1**（U1 脚 13/12/10），全在深睡唤醒要求的 GPIO0~5 内。原计划的 GPIO5 在符号左侧，走线会与电源交叉，所以换掉
- 🔴 **拨动开关必须串在电池与 C3 的 5V 脚之间**。C3 板上 Type-C 的 5V 直通 5V 脚，开关放别处的话，插 USB 烧录时 5V 会顺着 5V 脚倒灌回 TP4056 的 OUT+（OUT+ 与 B+ 直连，保护只切负极）= 拿 5V 怼电池。开关串中间 = 关掉就物理断开。**规矩：烧录前先关开关**
- **电池引线用 1×2 排针封装当焊盘**（不装排针）。**不能用 KF128 端子**：高 9.5mm，而板面以上只有 6.9mm
- **U1 选直插版**（`_TH`，库里还有个贴片版）。直插好焊但叠高多 2.5mm；想省高度就换贴片版，代价是半孔手焊

**两条 EDA API 退化（这次新发现）**：
- **网络标识（GND/5V 符号）放不进去**：`sch_PrimitiveComponent.create` 放 netflag 类型必定卡 30 秒超时，EDA 大概率弹了命名框。**绕法是重排版面让所有网络都能用普通导线连通且零交叉**，不依赖标识
- `sch_Net.getAllNetsName()` 也返回空（不只是导线的 `getState_Net()`）。网表只能坐标几何重建
- 桥有 **30 秒**上限：一次调用里塞十几个 API（尤其 `lib_Device.search`）会超时。**搜索结果要缓存，或直接用 `{libraryType:"2", libraryUuid, uuid}` 构造引用跳过搜索**
- `lib_Footprint.get` / `.copy` 对系统库封装**都抛不透明错**（`[object Object]`）→ 封装几何只能等落到 PCB 里再读

## 采购卡点（买错就装不上）

- **排母只买低背 5.0mm**，常见的 8.5mm 装不下
- **限位开关必须带簧片杠杆**（ZIPPY DF-P1S-1E-M-Z），无杠杆直动式行程 0.3mm 会被 3.3mm 凸轮升程压毁
- **轻触开关 6×6×12，动作力 100~160gf**，别买 300gf
- **拨动开关 SK12D07VG7**（卧式侧拨），不是立式的 SS12D00G3
- **MT3608 买 37×17 那款**（无 USB 座，实物尺寸图为准），SX1308 高 12mm 装不下

## 九条教训（都是真金白银换的）

1. **`Volumes=2 / Simple=yes` 只证明单件几何合法，完全不证明能装配。** v2.2 九件全过，用户仍发现 4 处装不上的硬伤。v2.3 起改用**布尔交集自检** `cad\check.scad`，并且**必须带阳性对照**（故意摆错必须非空），否则检测失效了都不知道。**但它测的是终态，测不出装配路径** —— 转毂穿不过壁孔就是自检抓不到的。
2. **模块叠高要一层层数。** DevKit = 排母 + **公排针塑料隔片 2.5** + 板 1.57 + 模组 3.1，四层。漏掉隔片那层就是 2.5mm，直接决定方案成不成立。
3. **转动件的限位不能靠"把挡块摆到那个角度"。** 挡块要待在转动件的**扫掠包络之外**，包络由"侧面到转轴的距离"决定而非角度。用**扫掠差集**生成位置，且**相邻角度实例必须取 `hull()` 填缝**——只做并集会在尖端半径漏出细缝，变成提前挡路的毛刺。
4. **几何"看起来对"不等于对。** D 形孔曾被写成 圆 **并** 方槽（应为 圆 **交** 半空间），渲染图上看不出来，实际轴插进去空转。这类问题只能用阳性对照钉死。

5. **跨零件的约束会在两边都改完之后失配，而布尔自检抓不到。** "按键 x<2，因为闸体占 2…48"这条注释写在按键参数旁边，后来按键位置改由 PCB 定、闸体也没人回头看，结果闸体正压在按键上。**求交永远是空的——两者根本不在同一个零件里。** 约束要写在会被改动的那一方，而且换事实源（这里是按键位置从"结构挑"变成"PCB 定"）时必须回头扫一遍引用它的注释。
6. **自检用例里不许留共面接触。** 面贴面求交，CGAL 给的是零体积薄片，导出 STL 有几百个三角形，按文件大小判"空/非空"会误判成非空。v3.0 第一轮 5 条假失败全是这个（交集 bbox 形如 `z[22.00..22.00]`）。凡"应该刚好贴上"的地方一律错开 0.01~0.05 再求交。**排查手段：看交集的包围盒，某一轴塌成一个数就是共面。**
7. **阳性对照要覆盖"东西根本不存在"。** 验开关底孔"没打穿外壁 / 是通的"那两条，**整块安装台不存在时照样过**——没有料求交当然是空的。补了"孔四周有料"的用例，而且**两块安装台分开验**：合成一条只要有一块在就非空了。
8. **探针直径要配孔的类型。** φ2.0 探 M2 过孔(φ2.4)合适，探自攻底孔(φ1.7)永远探不通——那是探针选错，不是零件有毛病。
9. **静态求交测不出装配路径，但可以换个写法测。** `t=40`：把"必须穿过 φ8.5 壁孔的那一段"减掉壁孔通道，剩下的必须为空；`t=41` 阳性对照把凸轮装回去（=一整件）必须非空。这条直接钉死了"转毂穿不过壁孔"那类问题。

**另加一条方法论**（2026-08-12 用户提出，已成为项目原则）：**先定元件尺寸，再动 3D。** v2.2~v2.6 连续四轮修的硬伤根因是同一类——拿没核实的元件尺寸建模。同理，**卖家详情页的"行程"是典型值，官方规格书的 `PT Max` 才是设计依据**（这条差点让一批限位开关全部失效）。

## 布线要点（2026-08-14）

**先算后画**：两个校验脚本在下笔前算间距（`clearance.js`：每段对所有异网焊盘+同层异网走线，阈值 0.2mm）、画完用回读铜箔验连通（`connect.js`）。一共拦下 30+ 处问题，其中三处是模型缺陷：**U1 的 24 个未用引脚也要避让**（两排 2.54 满排，穿越只有 1.02mm 的缝）、**贴片焊盘只在顶层不该双面挡**、**安装孔是独立焊盘 getAllPins 取不到**。

**0 过孔**：`pcb_PrimitiveVia.create` 建的过孔位置/网络/类型/尺寸全对，EDA 仍报"与同网络其它对象断开"，不认它导通（原因未明）。绕法是**所有换层都发生在 THT 焊盘上**。为此把 VBAT_PROT 改走底层、并**对调 J2 的两个限位端子**（限位开关是飞线接的，端子分配自由）——⚠ **J2.2=落杆限位、J2.3=起杆限位**，装配按此接。

**自动布线不可用**：`autoRouting()` 一律返回全部失败 duration:0；界面点按钮报"请先绘制板框"，但板框是好的（zoomToBoardOutline 返回 true、3D 能生成、6 段线闭合）。判断是该功能受限。

**覆铜只能手工画**（`IPCB_Polygon` 无公开构造方法，Polyline/Region/Pour 都要它）。⚠ **画完必须 `rebuildCopperRegion()`**，否则铜与走线间距为 0 等于全短路；⚠ **两面都要铺**，底层铜够不着顶层贴片的 GND 焊盘。
