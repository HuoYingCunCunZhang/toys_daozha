## 锁定决策

- **语音是核心**：ESP32-S3-DevKitC-1 **N16R8** + ESP-SR，仅 3 条命令（起杆/落杆/复位）。**无喇叭/无TTS/无录音回放**
- **无爆闪灯、无闸杆灯带**；指示灯方案 = **在模块自带灯正上方开观察孔**（底座对 TP4056 充电灯，遥控器对 C3 板载蓝灯）
- **防砸 = 行程超时反转**（落杆超 1.15×T 反转、超 1.5×T 进 FAULT）。⚠️ 曾定"堵转电流检测"，**已推翻**——成品 DRV8833 模块不引出 `AISEN`，电机电流不经过 `GND` 脚，电阻串 GND 只能读到几 mA 静态电流。代价：响应从毫秒级变**秒级（0.2~1.6s）**、压紧力约 1.3N
- 玩家 6~10 岁
- **尺寸**：底座 **163×63×25**，承载底板 **100×55**（换算 `BASE_L=板长+63`、`BASE_W=板宽+8`）；闸体 46×46×62；闸杆 300×5×8 **从按键相反侧(+X)伸出**；**转轴离地 42、杆顶 46**（用户小车最矮 50，必须低于它）；起杆 90°；底座 2 键；Type-C + 总开关在**前端面**；遥控器 60×30×20 三键
- **转毂拆成 `hub`（主体，一整件）+ `cam`（凸轮盘）** —— 拆件与电机固定无关，是壁孔 φ8.5 卡住了 φ18.6 凸轮和 36×14 臂。拆点选凸轮而非臂：凸轮不传扭矩不受弯，主体保持整体承力
- **电机只靠矩形隧道夹紧**，不做 M1.6 支架板（端面 M1.6 孔留作日后加固）

## 采购卡点（买错就装不上）

- **排母只买低背 5.0mm**，常见的 8.5mm 装不下
- **限位开关必须带簧片杠杆**（ZIPPY DF-P1S-1E-M-Z），无杠杆直动式行程 0.3mm 会被 3.3mm 凸轮升程压毁
- **轻触开关 6×6×12，动作力 100~160gf**，别买 300gf
- **拨动开关 SK12D07VG7**（卧式侧拨），不是立式的 SS12D00G3
- **MT3608 买 36×17 那款**（无 USB 座），SX1308 高 12mm 装不下

## 四条教训（都是真金白银换的）

1. **`Volumes=2 / Simple=yes` 只证明单件几何合法，完全不证明能装配。** v2.2 九件全过，用户仍发现 4 处装不上的硬伤。v2.3 起改用**布尔交集自检** `cad\check.scad`，并且**必须带阳性对照**（故意摆错必须非空），否则检测失效了都不知道。**但它测的是终态，测不出装配路径** —— 转毂穿不过壁孔就是自检抓不到的。
2. **模块叠高要一层层数。** DevKit = 排母 + **公排针塑料隔片 2.5** + 板 1.57 + 模组 3.1，四层。漏掉隔片那层就是 2.5mm，直接决定方案成不成立。
3. **转动件的限位不能靠"把挡块摆到那个角度"。** 挡块要待在转动件的**扫掠包络之外**，包络由"侧面到转轴的距离"决定而非角度。用**扫掠差集**生成位置，且**相邻角度实例必须取 `hull()` 填缝**——只做并集会在尖端半径漏出细缝，变成提前挡路的毛刺。
4. **几何"看起来对"不等于对。** D 形孔曾被写成 圆 **并** 方槽（应为 圆 **交** 半空间），渲染图上看不出来，实际轴插进去空转。这类问题只能用阳性对照钉死。

**另加一条方法论**（2026-08-12 用户提出，已成为项目原则）：**先定元件尺寸，再动 3D。** v2.2~v2.6 连续四轮修的硬伤根因是同一类——拿没核实的元件尺寸建模。同理，**卖家详情页的"行程"是典型值，官方规格书的 `PT Max` 才是设计依据**（这条差点让一批限位开关全部失效）。
