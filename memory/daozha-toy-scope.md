道闸（barrier gate）造型的儿童玩具，嘉立创打样 + 三维打印。目录 `D:\玩具\01.道闸门\`。

**工具环境**：OpenSCAD 2021.01 装在 `F:\Program Files\OpenSCAD\openscad.exe`（不在 PATH）。**OpenSCAD 在中文路径下无法渲染**，所以 CAD 工作副本放在 `D:\cad\`，项目目录 `cad\` 只是同步副本。命令行传 `-D part="x"` 的引号在 PowerShell 里会丢，已改用数字选择器 `-D p=N`。`--camera=` / `--imgsize=` 必须整体加引号。

文档：`道闸玩具_需求规格说明书_v2.md`、`道闸玩具_电路与结构设计方案_v2.md`（均为 v2.1）、`cad\daozha.scad`（**v2.4**）、`道闸玩具_紧固件清单_v1.md`（螺钉采购，已对齐 v2.4）、`道闸玩具_底板机械约束_v1.md`（底板外形/安装孔/净空/必须钉死的器件位置，喂给 PCB 布局那一步）、`道闸玩具_底板选型锁定_v1.md`（器件选型 + 原理图已连线校验）。`道闸玩具_电路设计方案_v1.md` 已过时。

**教训：`Volumes=2 / Simple=yes` 只证明单件几何合法，完全不证明能装配。** v2.2 九件全部通过这个检查，用户仍然发现 4 处装不上的硬伤（盖板螺丝孔没打穿背面止口、下壳螺柱没给止口让位、转毂插槽长宽装反、左右壳对拧只做了一边）。v2.3 起改用**布尔交集自检**：`cad\check.scad`，把"配合面不能重叠""螺丝路径要全通""同轴孔要真同轴"写成 intersection 用例跑一遍，期望空集；并且必须带阳性对照（t=11/12，故意摆错姿态必须非空），否则检测失效了都不知道。改任何配合尺寸后跑一次。

锁定决策：
- **语音是核心**，ESP32-S3-DevKitC-1 N16R8 + ESP-SR，仅 3 条命令：起杆/落杆/复位。**无喇叭/无TTS/无录音回放**。
- **无爆闪灯、无闸杆灯带** → 反馈只剩蜂鸣器（已知遗留项）。
- **防砸 = 电机堵转检测**（DRV8833 串 0.33Ω + ADC GPIO7），不用 VL53L0X。理由是覆盖范围（侧装有盲区，闸杆 300mm），不是价格。
- 电池 **103450 软包 1800mAh**（18650 装不下 20mm 高的底座）。PCB = 模块承载底板。玩家 6-10 岁。
- 尺寸：底座 150×55×20；闸体 46×46×62（顶面离地 82）；闸杆 300×5×8 **从按键相反侧(+X)伸出**；转轴离地 **42**、杆顶 46（用户小车高 50~100mm，须低于最矮的 50）；起杆 **90°**；底座 **2 键**；Type-C+总开关在**前端面**；遥控器 60×30×20 三键。

**OpenSCAD 建模踩过的坑**（改参数时注意，README 里也记了）：内腔挖空高度要减 2*WALL 否则捅穿顶盖；带孔螺柱不能在挖完内腔后 union（union 会把孔重新填实成密闭盲腔）；特征不能"刚好相切"到壁面（产生非流形）；底座内部特征必须写在 difference() 之外。

**Gmail 连接器权限不足**，无法建草稿/发邮件（用户邮箱 332437232@qq.com）。

**v2.4 重做了底座内部排布**（已完成）。真因是 `base_top` 的"止口"用 `rbox` 生成，那是**实心板**不是环，等于给内腔加了层天花板，净高 15→13。改成 `LIP_W`=6.5 的环后中央区恢复 15mm。同时把排布**翻转**：承载底板占 −X（正对前端面 Type-C/开关开口，老布局里 TP4056 在 x=+57、离开口 132mm 根本对不上），电池挪 +X。按键挪到 (−40,+10)/(−20,+10)。角螺柱挪到 (±70.5,±23) 并加粗 φ6 嵌进内壁。`PIV_Z` 改为 `PIVOT_ABS − BASE_H` 反推。

**未决（等用户拍板）：排母装不下。** 选型锁定里 U1/U2/U4 是 8.5mm 排母，叠高 13.3mm，而板面以上净空只有 **11.4mm**（板面 z=5.6，上盖背面 z=17）。两条路：**A（推荐）`BASE_H` 20→22 一行搞定**，净空变 13.4，选型/原理图一个字不用改，转轴因为已改成反推所以自动还在离地 42；**B 全部改直焊**，尺寸不动但模块不能插拔。详见 `道闸玩具_底板机械约束_v1.md`。
